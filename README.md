# Pizzeria Italy — End-to-End Business Analytics Dashboard (Power BI)
This project, developed as part of the Business Analytics and Data Culture course in the Master's in Data Analytics and Decision Support Systems, presents an end-to-end business intelligence solution developed in Power BI for Pizzeria Italy.

The primary objective is to transform raw operational and sales data into strategic insights for restaurant management, identifying opportunities to drive revenue, streamline operations, and optimize resource allocation. The project addresses key managerial challenges, including peak order hours, seasonal demand variations, table and seating capacity utilization (analyzing a 15-table and 60-seat layout), average order value, and menu performance to uncover best-sellers and underperforming products.

The implementation involved building automated ETL data pipelines in Power Query to ingest and clean transactional datasets, creating a robust dimensional model (Star Schema), and developing DAX metrics for time intelligence, revenue tracking, and capacity efficiency. The resulting multi-page dashboard combines intuitive data storytelling, custom visual components, AI-driven visual analytics, synchronized segmentation, and drill-through tooltips tailored for executive decision-making.

Together, this project demonstrates solid proficiency in data architecture, business acumen, and advanced reporting capabilities within Microsoft Power BI to support informed operational and corporate decision-making.
